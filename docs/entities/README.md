# Entities

This directory holds the diagrams and pages of kit's entities.

- Generated from the model, each page linking its diagram: [git](git.md), [git-repository](git-repository.md),
  [git-config](git-config.md), and [code](code.md), with `git.svg`, `git-repository.svg`, `git-config.svg`, and
  `code.svg`.
- Hand-made diagrams, replaced domain by domain when each is modelled: `actors`, `platform`, `work`, `delivery`,
  `trust`, `tools`, `configuration`, `conversation`, `content`, and `overview`.

The model, its files, and the commands that write the pages and diagrams are in [model.md](../model.md). The design is
[entity-model-design](../superpowers/specs/2026-11-15-entity-model-design.md).
